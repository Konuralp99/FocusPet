# 🤖 Focus Pet 2.0 - Senin Akıllı Verimlilik Asistanın

Focus Pet, ders çalışırken veya işine odaklanırken seni motive eden, dikkat dağıtıcı sitelere girdiğinde seni uyaran ve çalıştıkça XP kazanıp seviye atlamanı sağlayan bir masaüstü evcil hayvanıdır.

## ✨ Özellikler
- **Akıllı Takip:** Opera GX içinde bile YouTube/Netflix takibi.
- **Oyunlaştırma:** Çalıştıkça XP kazan ve robotunu geliştir.
- **AFK Algılama:** Masadan kalktığında otomatik uyku modu.
- **İstatistikler:** Detaylı odaklanma ve mola takibi.

## 🚀 Hızlı Başlangıç
1. **EXE Kullanarak (Önerilen):** GitHub'daki en son **Release** sekmesinden `FocusPet.exe` dosyasını indir ve çalıştır.
2. **Kod ile Çalıştırma:**
   ```bash
   pip install -r requirements.txt
   python main.py
   ```

## 🛠️ Nasıl Yayın Yapılır? (Geliştiriciler İçin)
Bu proje GitHub Actions ile otomatik yayınlanır:
1. Değişikliklerini GitHub'a yükle.
2. GitHub sayfasında sağdan **Releases** -> **Create a new release** de.
3. Bir tag seç (örn: `v1.0.0`) ve yayınla.
4. `.exe` dosyan otomatik olarak oluşturulup o release altına eklenecektir.
