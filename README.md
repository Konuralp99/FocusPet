# 🤖 Focus Pet 2.0
> **Masaüstü Verimlilik Asistanı ve Oyunlaştırılmış Odaklanma Sistemi**

Focus Pet, sadece bir uyarı sistemi değil; seninle birlikte büyüyen, çalışan ve seni motive eden yapay zeka tabanlı bir robot yardımcıdır. 

---

## ✨ Öne Çıkan Özellikler

| Özellik | Açıklama |
| :--- | :--- |
| **🎮 Oyunlaştırma** | Çalıştıkça XP kazan, seviye atla ve robotunu geliştir. |
| **🕵️ Akıllı Takip** | Opera GX içinde bile YouTube, Netflix gibi dikkat dağıtıcıları algılar. |
| **💤 AFK Tespiti** | Masadan kalktığında otomatik uyku moduna geçerek istatistikleri korur. |
| **📊 Detaylı Analiz** | `stats.json` ile günlük odaklanma ve mola sürelerini kalıcı olarak tutar. |
| **💬 Yaratıcı Mesajlar** | 30'dan fazla benzersiz, robotik ve motive edici diyalog. |

---

## 🚀 Kurulum ve Kullanım

### 1. Hazır Versiyon (EXE)
Kodla uğraşmak istemiyorsan, [Releases](https://github.com/Konuralp99/FocusPet/releases) sekmesinden en güncel `.exe` dosyasını indirerek doğrudan kullanmaya başlayabilirsin.

### 2. Geliştirici Kurulumu
Projeyi yerelinde çalıştırmak veya geliştirmek istersen:
```bash
# Depoyu klonla
git clone https://github.com/Konuralp99/FocusPet.git

# Bağımlılıkları yükle
pip install -r requirements.txt

# Çalıştır
python main.py
```

## 🛠️ Teknik Altyapı
- **Dil:** Python 3.10+
- **Arayüz:** PyQt6 (Transparent/Borderless UI)
- **Sistem Takibi:** Win32 API & psutil
- **Otomasyon:** GitHub Actions (CI/CD) ile otomatik .exe üretimi.
