# 🤖 Focus Pet 4.0 - AI Living Assistant
> **Oyunlaştırılmış Verimlilik, Derin Analitik ve Akıllı Robot Arkadaşın**

Focus Pet, sadece bir engelleme aracı değil; seninle birlikte büyüyen, çalışan ve seni bir "canavar" gibi odaklanmaya teşvik eden yapay zeka tabanlı bir robot asistanıdır.

| Özellik | Açıklama |

## 🚀 Kurulum ve Kullanım

### 1. Hazır Versiyon (EXE) - **ÖNERİLEN**
Kodla uğraşmak istemiyorsan, [Releases](https://github.com/Konuralp99/FocusPet/releases) sekmesinden en güncel sürümü indirebilirsin.

> [!IMPORTANT]
> **Klasör Önerisi:** İndirdiğin `FocusPet.exe` dosyasını Masaüstü'ne atmak yerine, **"FocusPet"** adında özel bir klasör içine koymanı öneririz. Uygulama, çalışma istatistiklerini (XP, Seviye vb.) `stats.json` adıyla bu klasöre kaydedecektir.

### 2. Geliştirici Kurulumu
Projeyi yerelinde çalıştırmak veya geliştirmek istersen:
```bash
# Depoyu klonla
git clone https://github.com/Konuralp99/FocusPet.git

# Bağımlılıkları yükle
pip install -r requirements.txt

# Çalıştır
python main.py
```
